# 實機自動收資料與 DAgger：定位 → 自動夾取 → 失敗時人工接手

目標：手臂自己跑「掃描 → 選方塊 → 夾取 → 放置」，人只在失敗時用 leader 接手修正。成功的自動回合和人工修正段都存成訓練資料，給座標 ACT 和 VLA 使用。

本文件是設計，依下方〈實作順序〉分段完成。程式沿用：
- `tools/finals_reach.py`：D455 定位、IK 對準；
- `agentic_sim.real_route`：Driver、固定路線、暫停選單、交接 leader；
- `agentic_sim.real_episode`：episode 格式，含 `command_source` 和 `takeover` 事件。

## 一個自動回合

```
停放位 ── D455 掃描 → 選目標（隨機，同 grasp 輪次）
   │
   ├─ 執行器（三選一）
   │    S1 程式：路線 → 方塊上方（IK、轉腕）→ 下降 → 閉爪 → 抬起 → 米盤格位上方 → 下降 → 張爪 → 抬起 → 起姿
   │    S2 程式到方塊上方 → ACT 接手到抬穩 → 程式放置
   │    S3 ACT 從停放位做完全程（條件：目標座標 + 落點座標，global 畫標記）
   │
   ├─ 監看（每一步都在跑）──→ 失敗 → follower 原地保持 → leader 自動帶到 follower 姿勢 → 倒數 → 人接手做完 → c
   │
   └─ 回停放位 → D455 量落點 → 自動判成功／失敗（人可改判）→ 存檔 → 下一筆（不還原，4→1 顆）
```

一輪 4 筆放完之後：
- 有人在場時，照現在的流程重擺。
- 自動還原（第 4 階段）：程式把米盤的 4 顆依序夾回粉盤，放到隨機的合法位置與角度。這段不當訓練資料，只記錄在 `reset/`。

## 自動失敗判斷

| 檢查 | 時機 | 判定 | 依據 |
|---|---|---|---|
| 卡住 | 移動中 | 落後超過 `PUSH_LAG` 且停滯 | Driver 既有的 `Paused`（stall） |
| 沒夾到 | 閉爪後、抬起後 | 夾爪讀數 < 12%（夾著方塊約 16.5%，空爪會閉到指令值 8%） | follower gripper 讀數 |
| 夾錯或掉落 | 抬起後 | 夾爪仍有物，但 D455 看到目標還在原位 | D455 掃描，手臂避開目標上方 |
| ACT 逾時 | S2、S3 | 超過 T 秒（預設 20 s）沒抬穩 | `review` 的 lift 判定 |
| ACT 越界 | S2、S3 | 末端超出工作區盒，或單步關節變化 > 15°（6°–15° 以每步 6° 帶過去） | FK 與限速 |
| 放錯 | 回停放位後 | 米盤沒有新方塊，或落點離格位 > 40 mm | D455 落點（`placed_block`） |
| 人工 | 任何時候 | 空白鍵：要求接手；Esc：原地暫停 | 終端鍵 |

判定失敗後，依失敗類型決定流程：
- 沒夾到：先自動重試 1 次（重新掃描、重新對準）。重試前後都記錄，重試又失敗才請人接手。
- 卡住、越界、人工要求：直接請人接手。

## 接手與紀錄（沿用 episode 格式）

- **每列標來源**：每一列 `control.jsonl` 記 `command_source`：
  - `script`：S1 程式；
  - `policy`：ACT；
  - `manual`：人。
  `task_is_policy` 在前兩種為 1。
- **交接事件**：由自動切到人工的那一列，記 `event.type = "takeover"`，內容包括：
  - `reason`（上表的檢查名）、`switch_ns`；
  - 被丟棄的待執行動作數；
  - 交接時的關節姿勢。
- **交接動作**：沿用 `Driver.align_leader`。follower 保持不動，leader 以 30°/s 帶到 follower 的姿勢，倒數後解 leader 扭力，之後 follower 跟隨 leader 的位移。
- **`review.json` 新增欄位**：
  - `mode`：`auto` / `dagger`；
  - `executor`：S1 / S2 / S3，以及 ACT checkpoint 路徑；
  - `interventions`：每次接手的幀號與原因；
  - `auto_result`：自動判定，`operator_result` 為人工確認。
- **失敗回合**：一律保留，放在 session 的 `dagger/`。成功的自動回合放 `episodes/`。這和人工示範的「失敗移出重錄」不同：DAgger 的價值就在失敗狀態後的人工修正。

## 訓練怎麼用

| 資料 | ACT（座標條件） | VLA |
|---|---|---|
| 人工示範（今天的輪次） | 全段 | 全段 |
| S1 成功回合 | 可選加入（`--sources script`）。動作比人平順，先比較加與不加 | 同左 |
| DAgger 修正段 | 從接手那一幀開始切成新的一段，條件相同。只學 `manual` 列（HG-DAgger） | 從接手幀起，語言指令不變 |
| 接手前的自動段 | 不進訓練，只用來分析失敗位置 | 同左 |

轉換工具 `real_to_lerobot.py` 要加的選項：
- `--sources manual[,script]`：依來源篩選列；
- `--from-takeover`：從接手那一幀切段。

## 安全

- 開扭力前照 AGENTS.md 確認起始姿勢、工作區淨空和停止方式。
- **程式移動**：關節速度沿用路線播放的上限 `PLAY_SPEED`。
- **路徑高度**：起姿到方塊上方的路徑，末端不低於 5 cm（`path_ok`）。
- **ACT 輸出**：每步關節變化限幅，工作區盒外的目標直接拒絕。超過時判為「ACT 越界」，請人接手。
- **收尾**：任何例外都走 `park_and_release`；Esc 一律原地保持，再由選單決定繼續、退回或解扭力。
