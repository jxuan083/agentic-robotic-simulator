# 場景、資產與任務

場地與任務分開：共用一組資產，以場地配置描述「東西擺在哪」，以任務描述「要做什麼」。任一任務都可載入任一場地。

## 場地配置

| 配置 | 內容 | 狀態 |
|---|---|---|
| `lab_current` | 對照實驗室桌面操作區、基座與相機，不重建整間房間 | 預計實作；先用暫定參數，量測後更新 |
| `competition_draft` | 比賽場地草案：兩張各 140 × 40 cm 桌面 | 高度與擺法待確認，取得現場資訊後改為實測版本 |

兩地沿用同一組托盤、相近相機視角與操作區配置，以減少背景差異；光照、影像尺度與位置變化仍須測試。

## 資產

| 資產 | 已知資訊／建立方式 |
|---|---|
| SO-101 | 優先引用 NVIDIA SO-101 Workshop 資產，核對實際夾爪、支架、基座與關節映射 |
| 積木 | 八色各八顆，邊長約 2.9–3.0 cm，整批平均 16.69 g。參數化立方體，含碰撞、質量與材質。近似建模值 0.0295 m、0.01669 kg（非逐顆實測）。八色依實物照片與量測紀錄為紅 red、橘 orange、黃 yellow、淺綠 light_green（偏黃綠）、深綠 dark_green、藍 blue、淺藍／青 cyan（偏青綠）、紫 purple；沒有實測色號，模擬用 RGB 為 provisional，見 `configs/palettes/block_colors.yaml`（`color_id` 固定，調整 RGB 不改 ID） |
| 放置區 | 米色大托盤，商品標示 36.5 × 26.5 cm |
| 儲存區 | 粉色中托盤，商品標示 30.5 × 23 cm |
| 托盤細節 | 深度估約 1 cm；內底、壁厚、盤緣高度、圓角待到貨後量測 |
| 桌面 | 淺白色靜態長方體，材質接近實際 |
| 相機 | Global 相機主要取景桌面，搭配腕部相機；依內外參與實際視角設定 |

建模注意：

- 托盤碰撞保留內部空間，不以整體凸包封住盤口。
- 摩擦、馬達動態與材質反射對照實機表現調整。
- 參考 NVIDIA SimReady 資產流程的尺度、外觀、物理與動態測試；簡單道具不必做完整 CAD／照片重建。文章與 Workshop 的軟體版本分開核對。
- Replicator 可用於影像標註與視覺變化；合成圖片本身不是 ACT 動作示範。

原始量測紀錄保留在量測來源，本文只記錄建模採用值。

## 暫定參數與量測

最小場景可以先用暫定參數建立，不必等量測完成。`SceneSpec` 中每個尺寸、位置與相機參數都標記來源：

| 標記 | 意義 |
|---|---|
| `provisional` | 暫定值（商品標示、估計、近似建模值），附說明 |
| `measured` | 實測值，附量測日期或版本 |

量測與相機校正是**實機對照的條件**，不阻塞初期 keyboard／mouse EE 模擬操作。進行實機對照（建置順序第 3 步）前需要：

1. 桌面長寬高、基座安裝位置。
2. 托盤內外尺寸與擺位。
3. 相機內參、外參與解析度（馬達 calibration 不等於相機外參校正）。
4. 附尺度參考的俯視與側視照片。

評估報表註明使用的場景版本含哪些暫定參數，避免把暫定場景的結果當成實機對照結果。

## 任務

| 任務 | 內容 |
|---|---|
| `sort_basic` | 三色單層抓放，固定托盤，改變積木位置 |
| `sort_distractors` | 少量非目標色與過量同色，先每輪 6–12 顆 |
| `sort_shortage` | 待命時移料，重新觀察後修改剩餘任務；流程見 [agent.md](agent.md#缺料流程) |

辨色測例：粉盤上的紅積木、米色盤上的黃積木。整盤可放上桌不代表每個角落都可抓到，可達範圍需另測。

## 建置順序

1. 最小 `lab_current` 場景（暫定參數）
2. keyboard／mouse EE 單顆抓放
3. 量測與相機校正後，實機對照與 leader 接合
4. 任務與隨機化
5. `competition_draft` 配置
